The Missing Piece in Cloudflare

What does out-of-band mean — and why does it matter?

Cloudflare has a WAF, bot management, DDoS protection, and Zero Trust. None of them understand what a user is saying to your LLM. An out-of-band firewall doesn't sit inline as a proxy — your app calls it as a separate API, gets a verdict, and then decides what to do next.

✖ In-band proxy

Sits between your app and the LLM. Every request goes through it. Any latency or failure in the proxy directly affects your users. Hard to deploy, hard to bypass for trusted flows.

Your App → [Proxy / Firewall] → LLM
△ single point of failure · added latency on every hop

✓ Out-of-band (this project)

Your app makes one extra API call before sending to the LLM. Gets a verdict. Decides what to do. The firewall is never in the critical path — you control the flow entirely.

Your App ————————→ LLM
      ↳ POST /v1/inspect → verdict
✓ no single point of failure · you own the logic
Built entirely with: Workers Workers KV R2 D1 Vectorize Workers AI No AWS. No GCP. No third-party AI APIs. 100% Cloudflare.

AI Firewall API

Edge inspection at the speed of a regex

Every prompt passes through a 4-layer pipeline. Each layer only runs when the previous one cannot make a confident decision. A "ignore all previous instructions" prompt is blocked in under 1 ms via heuristics, long before any AI model is called.

  • Layer 0 regex runs synchronously, zero I/O — catches known injection patterns instantly
  • Layer 1 + 2 fire in parallel — a KV cache hit short-circuits before vector search resolves
  • Layer 3 LLM only runs for Content Moderation profiles — most requests never touch it
  • Every violation carries a MITRE ATLAS technique ID (AML.T0051, AML.T0054…)
  • Profile-per-API-key: different apps get different detection rules, zero code changes

// Each detection setting maps to a rule function.
// Returns matched evidence string, or null.
const SETTING_RULES = new Map<string, (p: string) => string | null>([

  ['set-inj-override', p => {
    const m = INJECT_OVERRIDE.exec(p);
    return m ? m[0].slice(0, 120) : null;
  }],

  ['set-sensitive-api-key', p => {
    // Named vendor prefixes: sk-, ghp_, AKIA...
    const prefix = matchFirst(p, VENDOR_KEY_PATTERNS);
    if (prefix) return prefix.slice(0, 40);
    // Generic key: only trigger with surrounding context
    return contextAwareMatch(p, GENERIC_KEY_VALUE, KEY_CONTEXT, 80);
  }],

  ['set-obfusc-base64', p => {
    const m = BASE64_BLOB.exec(p);
    return m ? m[0].slice(0, 40) + '...' : null;
  }],
]);

// Short-circuit on first block-mode violation
export function runLayer0(
  prompt: string,
  activeDetections: ActiveDetection[],
): Violation[] {
  const violations: Violation[] = [];
  for (const ad of activeDetections) {
    for (const setting of ad.enabledSettings) {
      const evidence = SETTING_RULES.get(setting.id)?.(prompt);
      if (!evidence) continue;
      violations.push(buildViolation(ad, setting, evidence));
      // Exit immediately on block — skip all remaining layers
      if (ad.detection.mode === 'block') return violations;
    }
  }
  return violations;
}
AI Firewall Policy Manager

Admin control plane for security profiles

A separate Cloudflare Worker with a full web UI for managing who gets inspected and how. Every profile write syncs to Workers KV so the firewall picks up changes globally within 60 seconds — with zero downtime and no deploys.

  • Create SecurityProfiles with nested policies, detection categories, and per-setting modes
  • Issue, revoke, and rotate API keys — stored as SHA-256 hash, never plaintext
  • Write to R2 (durable source of truth) and push to KV (fast read replica) atomically
  • Full audit log: every admin action is appended to R2 with before/after snapshots
  • Add attack signatures: prompts are embedded by bge-small-en-v1.5 and upserted into Vectorize

// Create a profile: validate → persist → sync to KV → audit
app.post('/', async c => {
  const parsed = CreateProfileSchema.safeParse(await c.req.json());
  if (!parsed.success)
    return c.json({ error: 'Validation error' }, 400);

  const now = new Date().toISOString();
  const profile: SecurityProfile = {
    ...parsed.data,
    id: crypto.randomUUID(),
    createdAt: now, updatedAt: now,
  };

  // Push to R2 (durable) and KV (global fast-read replica).
  // firewall-api reads from KV at inspection time — never from R2.
  await syncProfileToKV(c.env, profile);

  // Append immutable audit record with full before/after snapshot
  await appendAuditLog(c.env, {
    action: 'create', resourceType: 'profile',
    resourceId: profile.id, after: profile, timestamp: now,
  });

  return c.json(profile, 201);
});

// syncProfileToKV: write profile doc + update all key pointers
export async function syncProfileToKV(env: Env, profile: SecurityProfile) {
  await env.POLICY_CACHE.put(
    `profile:` + profile.id, JSON.stringify(profile),
  );
  const keys = await listApiKeysForProfile(env, profile.id);
  await Promise.all(
    keys.map(k => env.POLICY_CACHE.put(`key:` + k.keyHash, profile.id))
  );
}

// POST /api/run-set: run a prompt set, record every result
app.post('/api/run-set', requireAuth, async c => {
  const { setId, profileId } = await c.req.json();
  const set = PROMPT_SETS.find(s => s.id === setId);
  const key = await getInspectKey(c.env.DB, profileId);
  if (!set || !key) return c.json({ error: 'Not found' }, 404);

  // Create run record before starting (so UI can show progress)
  const runId = crypto.randomUUID();
  await createRun(c.env.DB, {
    id: runId, ts: new Date().toISOString(),
    prompt_set_id: set.id, prompt_set_name: set.name,
    profile_id: profileId, profile_name: key.profile_name,
    username: c.get('user').username,
    total_prompts: 0, blocked: 0, monitored: 0,
    passed: 0, avg_latency_ms: 0,
  });

  // Fire all prompts via Service Binding (internal network, no TLS)
  const results = await Promise.all(
    set.items.map(item => runAndStore(c.env, item, set.id, runId, key.api_key))
  );

  // Compute and persist aggregate stats on the run
  const blocked   = results.filter(r => r.verdict === 'block').length;
  const monitored = results.filter(r => r.verdict === 'monitor').length;
  const avgMs     = results.reduce((s, r) => s + r.latency_ms, 0) / results.length;
  await updateRunSummary(c.env.DB, runId, {
    total_prompts: results.length, blocked, monitored,
    passed: results.length - blocked - monitored, avg_latency_ms: avgMs,
  });

  return c.json({ runId, results });
});
